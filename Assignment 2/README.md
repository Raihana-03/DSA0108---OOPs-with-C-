# Assignment 2 – CO2: Functions and Classes
One folder per question, each containing `code.cpp`, `output.txt`, `screenshot.png`, and `compile.txt`.

Compiler: g++ (C++17)
Compile: `g++ -std=c++17 -Wall -Wextra code.cpp -o program`
Run on Windows: `program.exe`; Linux/macOS: `./program`

Task01: call by value/reference/pointer, returned reference and default arguments.
Task02: return by reference, index, copy and const reference. Dangling reference is explained but not executed (undefined behaviour).
Task03: default arguments and overloads.
Task04: SavingsAccount class with private transaction array.
Task05: static members and arrays of objects.
Task06: friend functions and inline functions.
Task07: compare shifting history with circular-buffer redesign.

Before submission, add your name, register number and actual compiler version. Run the code yourself, take genuine terminal screenshots, record your own timings, and complete the predictions, explanations and complexity analysis requested in the assignment PDF. Task07 timings vary by machine and compiler settings.
